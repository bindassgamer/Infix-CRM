# Media Client Hub

CRM for Digital Media and automation:

I want to build frontend of a CRM where, I want Accounts, Contacts, Leads, Resources ,  Planning (Calender Scheduling) as side tabs on the left. 

I want to manage the leads , the number of working clients  and my team , planning and scheduling of the media uploads in calender,

Notification for different clients and payment alerts.
Smoooth UI and bifercate them into list and when the list table is clicked the details open , telling more about the plan and process
